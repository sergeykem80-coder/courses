# 🔐 API Документация: Аутентификация и Пользователи

## Базовый URL
http://localhost:8000/api/auth/

## Endpoints

### 1. POST /api/auth/register/ - Регистрация
### 2. POST /api/auth/login/ - Вход (JWT)
### 3. POST /api/auth/refresh/ - Обновление токена
### 4. POST /api/auth/logout/ - Выход
### 5. GET /api/auth/me/ - Данные пользователя
### 6. PUT /api/me/profile/ - Обновление профиля
